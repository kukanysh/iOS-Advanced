# Weather App

This is a simple weather app built using SwiftUI that fetches and displays current weather conditions, a 5-day forecast, and air quality data for a given city. It integrates with the OpenWeatherMap API and also displays a weather map layer showing temperature data, all within a user-friendly interface.

## Features

- **Current Weather**: Displays the temperature, weather conditions, wind speed, and air quality index.
- **5-Day Forecast**: View daily weather forecasts with temperature, description, and weather icons.
- **Weather Map**: Interactive map showing weather data (such as air temperature at a height of 2 meters) as an overlay, powered by OpenWeatherMap tiles.
- **Search**: Allows users to search for weather information by city name.
- **Map Annotations**: The map displays city markers, and tapping on them shows detailed weather data.

## Technologies Used

- **SwiftUI**: For building the user interface.
- **MapKit**: For rendering the map and adding weather layers.
- **OpenWeatherMap API**: Provides current weather, forecast data, and map layers.
- **UIKit (for map overlay)**: Used to display the OpenWeatherMap weather layer on the map.

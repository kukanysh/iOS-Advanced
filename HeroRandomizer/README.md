Hero Randomizer App

## 🚀 Features -

**Dynamic Superhero Fetching**: Retrieves a random hero from the API. -
**Async Image Loading**: Uses `AsyncImage` to load hero images with fallback states. - 
**Minimalist UI**: Clean design with rounded corners, shadows, and structured spacing. - 
**Error Handling**: Handles API errors and missing data gracefully.
